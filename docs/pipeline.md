# 代码化 Pipeline 设计

## 流程

```
源模型 (.glb/.gltf/.obj)
    ↓
[解析] 几何数据提取（顶点、面、材质、动画）
    ↓
[代码化] 国产模型生成 JS/TS 代码描述
    ↓
[验证] 代码生成的模型与源模型对比
    ↓
[调优] 迭代优化代码质量与还原度
    ↓
[归档] code/ 目录 + meta.json 更新
```

## 代码化目标

1. **几何代码化** — 将顶点/索引/法线/UV 转为程序化生成代码
2. **材质代码化** — 将 PBR 材质参数转为代码配置
3. **动画代码化** — 将骨骼动画转为代码驱动

## 验证指标

- 顶点数还原率：代码生成模型的顶点数 / 源模型顶点数
- 几何误差：Hausdorff 距离或类似度量
- 文件大小比：代码文件大小 / 源模型大小
- 渲染一致性：截图 SSIM 对比
